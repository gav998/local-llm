---
name: Portable local document tools
description: Правила безопасной работы локального агента с файлами и документами Office.
applyTo: "**"
---

- Для plain text, Markdown, JSON, CSV и исходного кода используй обычные
  инструменты чтения, поиска и редактирования файлов. Не проси пользователя
  запускать команду в терминале только для чтения такого файла.
- Для `.docx`, `.xlsx` и `.xlsm` вызывай инструменты `office` MCP напрямую.
  Изучай исходный файл до редактирования и проверяй результат после записи.
- По умолчанию сохраняй оригинальный Office-файл и пиши результат в новый файл с
  понятным именем, если пользователь явно не попросил перезаписать исходник.
- `openpyxl` сохраняет и записывает формулы, но не вычисляет их. Не утверждай, что
  результаты формул были пересчитаны.
- После создания или изменения файла сообщай его точный абсолютный путь.
