# Open WebUI

Запустите `start.bat` на Windows 11. При первом запуске скрипт скачает portable
Python 3.11, установит пакет `open-webui` и запустит сервер. После появления
строки `[READY]` откройте <http://localhost:8080>.

Системный Python, права администратора и изменение `PATH` не нужны. Runtime,
профиль пользователя, временные файлы, кэши, логи и данные Open WebUI остаются
внутри папки `webui`. Нажатие Enter в окне launcher останавливает сервер.

Другой порт можно указать параметром:

```bat
start.bat -Port 8081
```

Логи запуска находятся в `logs`, а постоянные данные, включая базу, загруженные
файлы и секрет сессий, — в `data`.
