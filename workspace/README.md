# Рабочие документы (необязательно)

Сюда можно класть DOCX/XLSX: содержимое папки игнорируется Git, а локальный агент
получает инструкции и portable-инструменты из соседней папки `office-tools`.

Копировать документы сюда необязательно. В portable VS Code добавьте любую папку
с компьютера через `File` → `Add Folder to Workspace...`. Она станет частью
multi-root workspace и будет доступна Local Agent. Добавлять весь диск можно, но
лучше расшаривать только рабочие каталоги: это быстрее и безопаснее.

Office-команды принимают абсолютные пути, например:

```bat
.\office-tools\office.bat inspect "D:\Документы\report.xlsx"
```
