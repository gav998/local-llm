# Инварианты GSM GOST

- Источник истины — OCR HTML/Markdown и provenance в manifest, а не языковая догадка.
- Порядок: строка источника, затем `main`, `duplicate`, `reserve`, `foreign`, затем позиция внутри ячейки.
- Не делить марки по запятой. Допустимые разделители: `<br>`, новая строка, элемент списка, нумерация и точка с запятой при нескольких явных НД.
- Не исправлять молча `С/C`, `О/0`, `З/3` и другие OCR-подмены.
- Связи имеют только типы `Дублирующая`, `Резервная`, `Зарубежная`.
- При одной основной марке все связанные позиции строки относятся к ней. При одинаковом числе основных и связанных позиций допустимо позиционное сопоставление. Иначе нужен review.
- Внутренний ключ марки — сочетание марки и нормативного документа. Внешние CSV имеют ровно согласованные русские поля.
- Staging хранит вхождения и provenance. Финальный экспорт объединяет Table 1 по внутреннему ключу, Table 2 и Table 3 дедуплицирует только по полному набору внешних полей.
- Не редактировать generated JSONL/JSON/CSV вручную. Исправления оформлять overrides через MCP; исходный raw OCR при этом сохраняется.
- Не разрешать блокирующую неоднозначность ради завершения счётчика.
